Start your project with Ganache
1. Start Ganache

Open Ganache and click Quickstart (or start your workspace).

You should see:

RPC Server:
http://127.0.0.1:7545

Keep Ganache running.

2. Deploy Contract to Ganache

Open terminal:

cd blockchain
npx truffle migrate --reset

or if you're using Hardhat with Ganache:

 -- > npx hardhat run scripts/deploy.js --network ganache

Only if your hardhat.config.js contains:

networks: {
  ganache: {
    url: "http://127.0.0.1:7545",
    accounts: [PRIVATE_KEY]
  }
}
3. Start Backend

-- > cd backend
-- > uvicorn main:app --reload

Expected:

Uvicorn running on http://127.0.0.1:8000
4. Start Frontend
-- > cd frontend
-- > npm install
-- > npm run dev

Expected:

http://localhost:5173
5. Connect MetaMask to Ganache

Add network:

Network Name: Ganache
RPC URL: http://127.0.0.1:7545
Chain ID: 1337
Currency Symbol: ETH

Import one of the private keys from Ganache accounts.
